# BuildSpace roadmap

## Phase 1 (complete)
- Research-first product brief and design vocabulary
- Initial project scaffold and environment setup
- Documentation for decision-making, design tokens and research references

## Phase 2
- Supabase schema and RLS policies
- Auth flow for email/password and Google sign-in
- Protected app shell and dashboard scaffolding

## Phase 3
- Calculation engine for all 13 project stages
- BOM generation and test suite covering reference house cases
- Rate override and source tracking UI

## Phase 4
- Wizard-based project creation
- Stage workspace, live totals and calculations drawer
- Autosave and undo/redo interactions

## Phase 5
- Nearby suppliers with Places proxy and map integration
- Verified supplier directory and WhatsApp/contact actions

## Phase 6
- 3D landing hero and stage visualizer with graceful fallback
- Contractor mode and detailed trade breakdowns

## Phase 7
- PDF and CSV exports, shareable reports, scenario comparison
- Estimate only disclaimers and reality-check panels

## Phase 8
- i18n, accessibility, responsive performance pass, Playwright smoke tests

## Phase 9
- README and deployment guide
- Final QA checklist and launch review

## Potential paid extensions
- Team workspaces and shared project collaboration
- Advanced BOM/vendor quote comparison
- Real-time rate feeds and regional refresh automation
- Branded PDF reports and custom templates
- Supplier promotion placements and verified directory tiers
- API access for builders, architects and construction software partners
